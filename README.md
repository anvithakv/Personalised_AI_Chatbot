# 🤖 Personalised AI Chatbot

An AI-powered personalised learning assistant built with Python and Google's Gemini AI. The chatbot provides intelligent responses based on the user's learning profile, including their learning topic, experience level, and goals.

## 🌟 Features

- 👤 Create personalised user profiles
- 🔄 Switch between multiple profiles
- ✏️ Update existing profiles
- 🗑️ Delete profiles
- 🤖 AI-powered responses using Google Gemini
- 🎯 Personalised answers based on the user's learning level and goals
- 💬 Interactive command-line chatbot
- 📜 Save chat history for each user
- 📂 Separate profile and history storage
- 🔐 Secure API key management using environment variables

## 🛠️ Technologies Used

- Python
- Google Gemini AI
- python-dotenv
- JSON
- Environment Variables
